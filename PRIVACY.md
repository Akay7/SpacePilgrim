# Privacy Policy

If you installed this application from Google Play, then Google Play does collect some personal data. Please see the privacy policy for Google Play Services here: https://policies.google.com/privacy

The game itself collects no personal data and sends nothing to the internet.

## Network games

**Multiplayer** can connect devices on the same local network (Wi-Fi) directly to each other: *Local network: On* hosts a game and *Join a network game* joins one. While you host or join a network game, the game exchanges only game data with the other devices of that game:

- the name of your device, so players can tell the devices apart. By default it is the phone's model or the computer's name; you can change it in the *Device name* box of the Multiplayer screen;
- the players' slots, colours and input, the state of the playing field, pause, and the results of the game;
- leaderboard entries: the nickname, points and time of each saved score. Connected devices keep each other's best scores in their own leaderboards.

A hosted game is announced to the local network so other devices can find it. None of this data leaves the local network, and nothing is sent to the developer or any other server.
